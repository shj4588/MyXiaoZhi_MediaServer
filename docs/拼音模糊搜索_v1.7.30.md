# v1.7.30 —— ASR 同音字纠偏（拼音模糊搜索引擎）

## 解决什么问题

STEM 语音点播《仙逆》时，麦克风/ASR 把「仙逆(xiān nì)」听成「写你(xiě nǐ)」。
服务端忠实拿「写你」回源搜索，结果播成《让你写卖鱼佬，你现场写高启强？》——
服务端、缓存、音频直链全部正常，**错在设备侧语音识别**。本版本在服务端加一层兜底：
把收到的词转成拼音，在已缓存/本地的书名里找读音相近的，命中即纠正。

## 设计原则

1. **零 npm 依赖**：拼音表 `files/pinyin_map.json` 离线生成（pypinyin 全字表 41923 字，
   取常用读音、去声调），运行时 `pinyin.js` 一次加载常驻内存。不改 Dockerfile，
   不往 arm64 容器里装 pinyin 库，避免 npm 源踩坑。
2. **三级链路，顺序兜底**：`本地库（字面+拼音）→ 磁盘缓存（字面+拼音）→ 在线回源`。
   拼音命中**早于在线回源**拦截——因为错词回源只会搜到错书（卖鱼佬）。
3. **不碰精确路径**：精确命中照原样返回，fuzzy 只在精确未命中时才介入，不误伤正常搜索。
4. **可关可查**：`?pinyin=0` 关闭兜底，`?fresh=1` 强制回源；命中应答带
   `cache:'pinyin'` / `fuzzy:true` / `hint:'拼音猜测：写你 → 仙逆…'`。

## 算法

核心武器 = **拼音首字母开头命中**：仙逆 `xn`、写你 `xn` → 命中；
而《让你写卖鱼佬》首字母 `rnxmlnxhgq` 不以 `xn` 开头 → 不误伤。
辅以全拼序列相似度（`xieni` vs `xianni` = 0.60）。综合打分：

| 判据 | 权重 |
|---|---|
| 首字母串以查询开头 | +3 |
| 首字母串包含查询 | +2 |
| 全拼以查询开头 | +2 |
| 全拼包含查询 | +1.5 |
| 全拼序列相似度 ×2 | 0~2 |

阈值 `PY_MIN = 3.0`。离线实测：真命中 4.20~7.00，误伤最高 1.33，安全边界充足。
